# Client

Aplicación web del proyecto, hecha con React.

## Qué irá aquí
- Interfaz de usuario: búsqueda y filtros de recambios, anuncios, perfiles y mensajería.
- Navegación entre páginas con React Router.
- Conexión con la API del servidor mediante Fetch.
- Estilos adaptables a móvil y ordenador.
- Tests del frontend con Vitest.
