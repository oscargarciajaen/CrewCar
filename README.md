# Grupo 3

Estudio que desarrolla una plataforma web para comprar, vender e intercambiar piezas y recambios de coche de forma técnica y segura.

## El problema
Encontrar recambios compatibles en plataformas generalistas es lento y expone a estafas, piezas incompatibles y tratos conflictivos. Nuestra plataforma ofrece un catálogo técnico con filtros por vehículo y una mensajería supervisada por IA que avisa a los moderadores de posibles fraudes.

## Stack
MERN: React con Vite (frontend), Node.js y Express (backend) y MongoDB Atlas (base de datos). Despliegue en Vercel y Render.

El proyecto está en la fase de planificación y aún no hay código que ejecutar. Las instrucciones de instalación y arranque se añadirán al empezar el desarrollo en la UD1.
