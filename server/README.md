# Server

API REST del proyecto, hecha con Node.js y Express.

## Qué irá aquí
- Registro e inicio de sesión (bcrypt y JWT) y roles de usuario y administrador.
- Rutas de anuncios, conversaciones y mensajes, alertas de stock y moderación.
- Conexión con la base de datos MongoDB Atlas mediante Mongoose.
- Análisis de conversaciones con IA para detectar fraudes.
- Tests del backend con Jest y Supertest.
