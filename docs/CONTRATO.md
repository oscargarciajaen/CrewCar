# Contrato de equipo · Grupo 3

## Compromisos

El equipo se compromete a invertir una media de 3:30 horas a la semana en el proyecto, si alguien no llega a ese tiempo estandarizado se revisará su trabajo y evaluará si tendrá que hacer tiempo extra la semana siguiente.

## Comunicación

Los canales de comunicación serán Whatsapp y un servidor de Discord. El plazo de respuesta es de 10:00 a 20:00. Escribiendo concretamente "Tengo un bloqueo".

## Decisiones y conflictos
Cuando los miembros del equipo están en desacuerdo cada uno dice su motivo explicándolo y cuando todos se hayan escuchado se hace votación, si hay empate se vuelve a hablar. Si una persona no aporta tiene 3 avisos.

## Calidad
Debe tener la información bien escrita y detallada de una manera fácil de entender.
Otro miembro o varios de ellos revisarán cuidadosamente dicho PR para ver si cumple los controles de calidad si no los tiene o el equipo puede ver una mejora se volverá a hacer teniendo en cuenta dichos problemas o mejoras el contenido.
